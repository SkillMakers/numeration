Exercice 1 - convertir 156 en binaire (divisions successives par 2)
========================================================================
  156 / 2 =  78  reste 0
   78 / 2 =  39  reste 0
   39 / 2 =  19  reste 1
   19 / 2 =   9  reste 1
    9 / 2 =   4  reste 1
    4 / 2 =   2  reste 0
    2 / 2 =   1  reste 0
    1 / 2 =   0  reste 1
  on lit les restes de bas en haut : 156 = 1001 1100
  verification : 128 + 16 + 8 + 4 = 156
  Python : bin(156) = 0b10011100

Exercice 3 - l'hexadecimal : paquets de 4 bits, et 2026 en base 16
========================================================================

     7 / 16 =   0  reste  7 -> 7

  Python : hex(2026) = 0x7ea

Exercice 5 - ecrire -5 sur 8 bits, de trois facons
========================================================================
  +5                      : 0000 0101
  signe et valeur absolue : 1000 0101
  complement a un         : 1111 1010
  complement a deux       : 1111 1010 + 1 = 1111 1011
  les deux zeros :
    signe et valeur absolue : +0 = 0000 0000, -0 = 1000 0000
    complement a un         : +0 = 0000 0000, -0 = 1111 1111
    complement a deux       : un seul zero, 0000 0000
  5 + (-5) : 0000 0101 + 1111 1011 = 1 0000 0000 -> sur 8 bits : 0000 0000 = 0
  Python : (-5) & 0xFF = 0b11111011

Exercice 6 - lire un octet : non signe ou signe ?
========================================================================
  1111 1111 : non signe 255, en complement a deux   -1
  1000 0000 : non signe 128, en complement a deux -128
  0111 1111 : non signe 127, en complement a deux  127
  1111 1011 : non signe 251, en complement a deux   -5
  plages :
     4 bits : non signe 0 a 15 ; signe -8 a 7
     8 bits : non signe 0 a 255 ; signe -128 a 127
    16 bits : non signe 0 a 65 535 ; signe -32 768 a 32 767
    32 bits : non signe 0 a 4 294 967 295 ; signe -2 147 483 648 a 2 147 483 647
  Python : int.from_bytes(b'\xff', signed=True) = -1

Le piege - l'oppose de -128 sur 8 bits
========================================================================
  -128           = 1000 0000
  on inverse     = 0111 1111   (127)
  on ajoute 1    = 1000 0000   (-128)
  l'oppose de -128 est -128 : +128 ne tient pas sur 8 bits (maximum 127)
  valeurs de -128 a 127 dont l'oppose est faux : [-128]
  meme chose sur 32 bits : oppose de -2147483648 = -2147483648

Exercice 9 - coder -6,25 en IEEE 754 simple precision
========================================================================
  6,25 = 110,01 = 1,1001 x 2^2
  exposant stocke = 2 + 127 = 129 = 10000001
  signe 1 | exposant 10000001 | mantisse 10010000000000000000000

Le 0,1 en flottant
========================================================================
  0,1 en simple precision : 3DCCCCCD, valeur stockee 0,100000001490116119384765625
  0,1 en double (Python)  : 0,1000000000000000055511151231257827021181583404541015625
  0.1 + 0.2 = 0.30000000000000004
  0.1 + 0.2 == 0.3 -> False
  abs((0.1 + 0.2) - 0.3) < 1e-9 -> True
